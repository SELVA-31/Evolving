# Phrase bank · technical writing

Reuse these in READMEs, journal entries and LinkedIn posts. Add 5 new ones every Sunday (from datasheets, app notes, good posts).

| Use | Phrase |
|---|---|
| Goal | The goal of this experiment was to … |
| Prediction | I expected …, but I measured … |
| Error | The main error source is …, which contributes about … mV. |
| Trade-off | This is a trade-off between … and … |
| Validation | To validate this, I compared … with … |
| Result | The measured value is within ±… of the reference. |
| Industry link | This matters in real products because … |
| Next step | Next, I will … to reduce … |
| Surprise | One thing that surprised me was … |
| Summary | In short, … |
