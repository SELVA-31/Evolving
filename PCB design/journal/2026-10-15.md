### Step 3 · Tour + hotkeys (0:30–0:55)
Where: the official EasyEDA Pro documentation site. Open these links in Chrome on the PC (or on the phone):

- [ ] **Design Flow** (5 min): https://prodocs.easyeda.com/en/introduction/design-flow/ — the order of work: library → schematic → PCB → outputs. This is the loop we repeat all 7 weeks.
- [ ] **Hotkeys** (5 min): https://prodocs.easyeda.com/en/introduction/hotkeys/ — the default keys. In the editor the same list is at **Top menu → Settings → Shortcuts**. `journal/hotkeys.md` is already pre-filled with the defaults the docs list; fill the blank rows from the Settings → Shortcuts dialog.
- [ ] Bookmark the **Quick Start** for the whole week: https://prodocs.easyeda.com/en/quick-start.html — it walks through install → interface → symbol → footprint → project → schematic → PCB → manufacturing files → order. When a step on Fri or Sat is unclear, this is where to look first.
- [ ] Find these panels in your editor: bottom **Library**, left **Project**, left **Net**, right **Property**, bottom **DRC**.

### Step 4 · Warm-up, twice (0:55–1:35)
Round 1 (25 min), in the schematic:
- [ ] Bottom Library → search `0603 10k` → filter **JLCPCB Basic** → place a resistor.
- [ ] Same for: `0603 100nF` capacitor, `0603 red LED`, `TP4056`, `DW01A`, `FS8205A`, `USB-C 16 pin` (any Basic or cheap Extended receptacle is fine today).
- [ ] Draw 5 wires between pins. Place net labels `GND` and `VBUS` on two wires. Place a GND net flag and a VCC/VBUS net flag.
- [ ] Design → **Annotate Designator**. Design → **Check DRC**. Read what it says.
- [ ] Design → **Update PCB** (or Convert to PCB). In the PCB, look at the thin ratlines between pads. Do not route.

Round 2 (15 min): delete everything in the schematic and the PCB, do Round 1 again, faster. Write the time: Round 1 ____ min · Round 2 ____ min.
